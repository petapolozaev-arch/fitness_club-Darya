# Библиотека (ООП, 2 курс)

Десктопное приложение на Python + Flet.

## Запуск

pip install -r requirements.txt
python main.py

## Возможности

- вход по логину
- каталог книг, поиск и фильтр по жанру
- выдача и возврат книг
- сохранение отчёта в report.txt при выходе

## ООП

- абстрактный базовый класс
- наследование, магические методы, геттеры и сеттеры
- своя замена dict — класс CustomMap
- переопределённые UI-компоненты
