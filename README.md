# Фитнес-клуб (ООП, 2 курс)

Приложение на Python + Flet 0.24.1 для записи тренировок.

## Что умеет

- вход по логину и имени
- абонемент на 10 занятий
- расписание из 10 тренировок, запись и отмена (лимит 4 активных)
- сохранение отчёта в report.txt при выходе

## Запуск

    pip install -r requirements.txt
    python main.py

## Что по требованиям ООП

- абстрактный класс `Base` с методами `short()` и `full()`
- классы `Training` и `Client` — наследники `Base`
- своя замена dict — класс `MyMap` (два списка вместо словаря)
- 10 переопределённых UI-компонентов: `MyText`, `Header`, `MyField`,
  `Btn`, `Row2`, `Col2`, `Card`, `MyList`, `MyDropdown`, `Line`
- магические методы `__eq__`, `__lt__`, `__gt__`, `__repr__`, `__str__`
- геттеры и сеттеры на всех атрибутах

## Структура

    main.py          весь код
    requirements.txt зависимости
    report.txt       создаётся при выходе
